  \item createGraphics can be used to attach this extra canvas onto the drawing platform
\end{itemize}

\subsection*{2. for the 3D terrain build up}

\begin{itemize}
  \item 3D terrain is actually manipulation of x, y, z coordinates
  \item in this project, x coordinates represents the spectrum position (0 to 1024)
  \item y coordinates represents the number of vertices
  \item z coordinates represents the amplitude of sound with that specific spectrum position
  \item these three factors makes each of the vertex points on the terrain
  \item three adjacent vertices forms one surface, and many surfaces forms the complete terrain
\end{itemize}
