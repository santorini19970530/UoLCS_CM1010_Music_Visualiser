\chapter*{Final Project Submission}

%% Overview
\section*{Overview}
In this assignment you will need to submit the finalised code you have produced for your project and written responses to the report prompts in the ‘My Assignment’ tab.\\
You will be assessed on the quality and complexity of your code, its stability and the answers you provide for the report. See the review criteria summary below for details\\
The report prompts in the ‘My Assignment’ tab allow you to include images, headings and text formatting. Make sure you use the features to highlight your points clearly.\\
\textbf{You must not write more than the stated word limit for each prompt or you will lose marks (10$\%$ discretion will be applied, so for a 400 word limit, 440 words or less will not be penalised).\\
You can write less words without any penalty. }

\section*{Questions}

%% Question 1
\subsection*{Question 1}
Upload your completed project files as a zip.\\
Please don’t use any other compression file formats.

%% Question 2
\subsection*{Question 2}
List the modifications and extension that you have made to the template file (400 words).\\
For each extension your answer should include:
\begin{itemize}
  \item What is the function of the extension?
  \item How does the code fit into the templates design?
  \item How have you structured the extension's code?
\end{itemize}

%% Question 3
\subsection*{Question 3}
Describe how effective your plan was in completing your project (250 words).\\
Your answer should include:
\begin{itemize}
  \item How well did you stick to your schedule?
  \item Did you divide up the task and the time effectively?
  \item Did you have an unexpected difficulties or challenges? 
\end{itemize}

%% Question 4
\subsection*{Question 4}
Evaluate the process of completing the project and how effective the final product is. (250 words)\\
Your answer should include:
\begin{itemize}
  \item \textbf{Self evaluation of the process of completing the project.}
    \begin{itemize}
      \item You may find it helpful to reflect on your plan and think about what you might do differently next time. 
    \end{itemize}
  \item \textbf{Have you performed any system testing or user testing on your application?}
    \begin{itemize}
      \item What errors did you uncover?
      \item How did users respond to the application?
      \item How would you rectify these in a future version of the application?
    \end{itemize}
\end{itemize}

%% Question 5
\subsection*{Question 5}
List any external sources that you have actively utilised in your project.\\
Your answer should include:
\begin{itemize}
  \item any code you have used from external sources verbatim
  \item any code where you have taken inspiration from although adapted and refined for the project (such as pseudocode algorithms or code pens)
  \item any online help forums you have taken code from (i.e. StackOverflow or library documentation)
  \item any third-party libraries you have used.
\end{itemize}
You do not need to include everything you have read or that has helped you. Only where you have used or adapted code that appears in your project.\\
This can be a revised version the answer you provided for the midterm.\\
\textbf{There is no word limit for this answer.}
