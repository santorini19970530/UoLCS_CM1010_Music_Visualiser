Outlook

* remade the outlook to mp3 player

* this is made by extra objects, and application of Strategy Pattern for the player buttons

* the player framework in $music_player_frame.js$, and the buttons strategies code are in buttons folder

* buttons include play-stop, speed control and volume control. Strategy Pattern is used to structure the coding: each of them are assigned one draw strategy and one hit check strategy

* each buttons, when mouse pressed, are not allowed to change screen display size (other parts of canvas can)

* I prefer using keyboards then using mouse click. so i set up key-mapping switch-case code block to initiate respective functionu

* for testing purpose, I have also added some callbacks to confirm all recource files are being loaded (shown by console.log() code)
